# Hacker News 

Ссылка на демо: [Hacker News Client]()

Клиентское приложение для чтения Hacker News, построенное на React и Redux с использованием официального API. С использованием языка TypeScript.

## 🚀 Функционал 


- **Главная страница:** Вывод 100 свежих новостей с автоматической сортировкой по дате.
-**Страница новости:** Детальная информация и древовидные комментарии (подгрузка вложенных веток по клику).
-**Обновление:** Кнопки принудительного обновления для новостей и комментариев.
-**Навигация:** Роутинг без перезагрузки страницы.

## 🛠 Стек технологий
-**Core:** React 18, Redux Toolkit
-**Routing:** React Router v6
-**UI Library:** Ant Design
-**API:** Hacker News API (Axios)
-**Styling:** CSS-in-JS 
-**Language:** TypeScript

## 📦 Установка и запуск


1. **Клонируйте репозиторий:**
   ```bash
  git clone https://github.com/Alesya98/Hacker-News
  cd HACKER-NEWS

2. **Установите зависимости:**

npm install

3. **Запустите проект:**

npm run dev

Приложение будет доступно по адресу: http://localhost:3000

## 🏗 Архитектура проекта
src/components — общие UI-компоненты (списки, карточки).
src/pages — основные экраны.
src/redux — конфигурация Redux, слайсы для новостей и комментариев.
src/API — логика взаимодействия с Hacker News API.
src/utils — хелперы для форматирования дат и работы с деревом комментариев.
src/hooks -  пользовательские (custom) хуки для выноса логики из компонентов.
src/types - TypeScript-интерфейсы и типы для описания структуры данных.
